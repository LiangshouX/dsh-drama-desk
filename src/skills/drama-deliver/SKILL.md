# 成片交付

1. 用 `drama_desk_production` 读取 stage=deliver，再读当前规范。检查 finals、exists、stale、ready 与 blockers。
2. 文件缺失、资产已作废、来源镜头有变化时，回装配处理。仅有 final 字样不能证明成片可用。
3. 请导演在工作台回看当前成片，核对顺序、节奏、声音、画幅。保留尚未完成的字幕、配乐或精剪项，不隐瞒粗剪的限制。
4. 仅在导演明确认可这一版时调用 `drama_desk_deliver`，指定 workspace 与 asset。它会再次检查来源与前置条件，记录交付 ID 和时间。
5. 成片可在交付页下载。不得自动发布到外部平台，也不删除历史版本。
