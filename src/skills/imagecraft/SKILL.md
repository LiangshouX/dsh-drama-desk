# ImageCraft · 高质量生图方法论

> 本 Skill 是**独立技能**，不属于 drama 流水线，不依赖 `spec/` 记忆层。成熟后再与 drama 工作流集成。
> 所有结论均来自实测（探针记录见 `references/实测案例库.md`，证据图见 `assets/probe-sheets/`）。

---

## 0. 一句话总纲

**锚点是真相，提示词只是路由。** 想不清楚的时候，永远先改锚，再改词。

---

## 1. 七条硬规则（违反其中任何一条，产出必然掉档）

| # | 规则 | 后果 |
|---|---|---|
| **A1** | **锚点决定成品的天花板**。锚里有什么，输出就有什么——包括画风、材质、骨相、光比，不只是"媒介"。 | 用弱锚出强图＝做梦 |
| **A2** | **锚会沿生成链降级传递**。永远用**最佳原图**当锚，**禁止用自己上一轮的输出**当锚。 | 自产锚 = 每一轮掉一档，几轮后彻底塌 |
| **A3** | **词表决定落点簇**，与画风标签无关。三簇：① 影视CG机制语汇 → 剧情CG；② 二次元/立绘标签 → 手游立绘；③ 中性客观描述 → 通用壁纸（**陷阱档**）。 | 同一模型、同一题材，差一个量级 |
| **A4** | **脸的有效像素 = 脸在画面中的占比**。低于 1/6 必然脸废；**1/4 是甜点**（中近景）。全身图必须补超分。 | 全身图的脸 = 模板娃娃脸 |
| **A5** | **否定项会反向激活被否概念**（实测：7 条否定 → 婴儿肥大眼；`not a villain` → 更像反派）。**按层设上限**：面部层 **0 条**（纯正向描述）、媒介层 **≤2 条**、格式层可放宽但该层正向词必须同等密集。 | 越写"不要"越出"要" |
| **A6** | **单次采样方差很大**。任何对比结论必须 **n≥2**，且用**读数比对**（`image_qc.py`）看组内极差，不能凭单张下判断。 | 容易把噪声当因果，然后写进错误规则 |
| **A7** | **纵深靠三层，不靠堆料**：前景遮挡物（虚化）＋ 中景主体（清晰）＋ 背景层次化（虚化成块）。 | 背景平、像贴图 |
| **A8** | **不把拼图塞进模型上下文**。大尺寸多脸拼图会被输入审核判敏感，**永久卡死会话**。审图用 `image_qc.py` 读数；必须看图时由**人**看原图。 | 一次拼图 = 会话报废数天进度 |

## 2. 五步工作流

```
① 定锚          选出质量最高的那张图当风格锚（不是最近生成的）
② 选档位        近中景 / 中景 / 全身 / 特写 —— 按"脸要多大"反推
③ 写词表        七段式（见 §4），画面类型声明必须在最前
④ 批量探针      一次提交 n≥2，预算允许时同 prompt 多锚对照
⑤ 读数验收      跑 image_qc.py 出体检表看数字（不要拼图、不要 read_image）
                见 references/探针方法论.md §3
```

> ⚠️ **⑤ 是 2026-11-15 改的**：原为「拼图验收：缩略图拼版横向比」。
> 拼图会被输入审核判敏感并**永久卡死会话**（已发生 3 次）。
> 现在改为读数：模型读文本报告，不读任何图。

## 3. 锚点纪律速查

### 锚的三种职责

| 锚类型 | 内容 | 声明写法 |
|---|---|---|
| **风格锚** | 全片统一画风/材质/影调 | `图1 仅作为渲染语言的风格锚：取它的材质表现力、光影层次、色彩分级与景深质感` |
| **身份锚** | 某个角色的脸与身形 | `图1 是身份锚：严格保持这张脸，不改变五官比例与骨相` |
| **场景锚** | 同一空间的陈设/空间关系 | `图1 是场景锚：保持同一空间布局，不要移动任何家具` |

### 图序

**风格锚放最后**：模型先读到的图权重更高，前面放身份/主体图更稳。

### 声明必须写"不取什么"

只写"取什么"模型会把锚的构图、人物、场景一起搬过来。必须显式排除：

```
不要沿用图1的人物、面容、发型、服装、姿态与场景内容；人物与场景全部重新设计。
```

### 选锚检查表

- [ ] 这是**质量最高**的那张，不是我刚生成的？
- [ ] 它的**光比**是我要的？（锚会连带继承光比）
- [ ] 它的**骨相**是我要的？（锚会连带继承脸型）
- [ ] 它的**题材与目标场景同族**吗？（同族＝加分，异族＝需要更强的词表补偿）

## 4. 提示词七段式

顺序固定，**① 必须最前**（模型先读到锚的归属，后面文字才有主人）。

```
① 锚点职责声明   图1 是风格锚／身份锚／场景锚，取什么、不取什么
② 画面类型声明   影视级 CG 剧情画面，不是插画、不是立绘、不是二次元插画风
③ 镜头段         焦段感 / 景别 / 占幅 / 机位高度 / 景深 / 前景入画物
④ 光线段         主光方向与性质 / 明暗比 / 暗部处理 / 补光 / 轮廓光 / 体积光
⑤ 色彩段         主调 / 饱和度 / 冷暖关系 / 明度分区
⑥ 主体段         人物（骨相→眼→发→肤→服饰→手→神态）或场景（陈设→纵深→氛围）
⑦ 排除段         按层设上限（见下）
```

### 否定项分层（A5 的落地细则）

「≤2 条」是**面部层**的实测结论，不是全提示词的总配额。分三层各设上限：

| 层 | 上限 | 依据 | 写法要求 |
|---|---|---|---|
| **面部层**（脸/眼/神态） | **0 条** | 实测 7 条否定 → 婴儿肥大眼；`not a villain` → 更像反派 | 纯正向。脸型/眼型/瞳形/高光/唇逐项写出来，负向意图改写成正向形态（如「不要黑眼圈」→「a very faint barely-there cool grey shadow under the eyes」） |
| **媒介层**（画风/上色/材质） | **≤2 条** | 排除最容易反向激活的是"画风"类概念（照片写实 / 3D / 厚涂） | 选最致命的两条，其余删掉；同层正向词必须写足（赛璐璐平涂色块配硬边阴影、叠加一层轻薄透明水彩晕染、松软暖棕铅笔与淡墨线） |
| **格式层**（文字/水印/边框/第二人物） | 可放宽 | 这些是低歧义的构图约束，反向激活风险低；本项目实测每张带 3–4 条未出问题 | 但该层的正向描述（构图、占幅、画幅、背景色）要同样具体，不能只写排除 |

> ⚠️ 反例：把面部层的否定顺手搬到媒介层，或反过来用媒介层的密集正向词去"稀释"面部层的否定——
> 两者都会让 A5 失效。**否定项要按层放，不要按总数放。**

**可直接复制的影视 CG 词表**（见 `references/影调与光.md` 全文）：

```
画面类型：影视级 CG 剧情画面，不是插画、不是立绘、不是二次元插画风。
镜头：35mm 电影镜头，中近景（腰部以上），人物居中，机位与眼齐平，
      浅景深，背景虚化成柔和色块，前景一枝〔某物〕虚化入画。
光线：低调侧逆光为主光，从人物左后上方斜射，轮廓光勾勒发丝与衣缘；
      暗部保留细节不压死，柔和面光补亮面部；暖光与冷雾形成冷暖对比。
色彩：低饱和电影调色，〔主色〕与〔对比色〕并置，不要通体高饱和〔某色〕。
```

## 5. 什么时候必须停下来问人

- 用户只给了**一张参考图**却想要"完全不同的角色" → 身份无法凭空生成，需确认是否接受新建脸。
- 用户要**同一角色多镜头** → 必须先产定妆脸并锁定为身份锚，否则脸必崩。
- 成本敏感且要批量 → 先按 §2 ④ 跑小批对照（2–3 张），再放量。

## 6. 验收门槛

不通过就返工，不要"将就用"：

- [ ] 与锚并排，**光比、骨相、材质**是否同档
- [ ] 脸占画面是否 ≥1/4（特写/全身另议）
- [ ] 有无暗部层次，还是通体平亮
- [ ] 背景有没有三层纵深
- [ ] 有无文字/水印/第二人物
- [ ] 手与饰品是否正常（多指、糊成一团）
- [ ] 与上一张并排，**画风是否漂**（这是最常见的隐性失败）

## 8. 硬边界

- 本 Skill **只管提示词与锚点**，不负责视频、配音、剪辑。
- H3-Image **接口不幂等**：重复提交＝重复扣费。批量前先落台账，失败先查台账再决定是否重发。
- 付费生成前若用户未指定数量/尺寸，按最小可用规格（2K / n=1 或 2）执行，不擅自上 4K 大批量。
