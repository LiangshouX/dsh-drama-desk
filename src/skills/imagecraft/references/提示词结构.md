# 提示词结构

> 七段式骨架、语汇分簇、危险词表、面部公式。

---

## 1. 七段式骨架

顺序固定。**① 必须最前**——模型先读到锚的归属，后面的文字才有主人。

```
① 锚点职责声明    图1 是风格锚／身份锚／场景锚，取什么、不取什么
② 画面类型声明    影视级 CG 剧情画面，不是插画、不是立绘、不是二次元插画风
③ 镜头段          焦段感 / 景别 / 占幅 / 机位高度 / 景深 / 前景入画物
④ 光线段          主光方向与性质 / 明暗比 / 暗部处理 / 补光 / 轮廓光 / 体积光
⑤ 色彩段          主调 / 饱和度 / 冷暖关系 / 明度分区
⑥ 主体段          人物或场景
⑦ 排除段          ≤2 条
```

## 2. 词表分簇（最重要的杠杆）

**实测（案例 B）：同一锚、同一主体，只改词表，输出差一个量级。**

| 簇 | 触发词 | 落点 | 实测表现 |
|---|---|---|---|
| **影视 CG 机制簇** | 电影镜头 / 焦段感 / 侧逆光 / 暗部保留细节 / 冷暖对比 / 低饱和电影调色 | 剧情级 CG | 体积光、真实焦外、骨相清晰、暗部有层次 |
| **摄影器材簇** | ARRI Alexa / 50mm f1.4 / 胶片颗粒 / 黄昏 | 影楼写真风 | 比机制簇多一层"写真味"，面部光偏平，暗部层次弱 |
| **二次元标签簇** | 国漫 / 仙侠 / 手游宣传立绘 / 仙女 / 俏皮 / 高饱和 | 手游立绘 | 大眼小鼻、超高饱和、大量飘带、梦幻 bokeh |
| **中性客观簇** | "一位少女站在桃花林中，穿粉色裙子" | **通用壁纸（陷阱档）** | 平光、无纵深、无体积光、构图平庸、脸僵 |

**结论**：
- 最佳 = **机制型词表**（镜头几何 + 光位 + 材质 + 调色），不是器材名词。
- 器材名词容易滑向"写真/婚纱"。
- **"中性客观描述"是最危险的写法**——它既不触发影视簇也不触发插画簇，落在训练分布均值。
- 标签词（国漫/仙侠/立绘）会**直接把你拽进二次元簇**，哪怕锚是影视级 CG。

## 3. 危险词表（H3-Image 实测）

| 词 | 后果 | 替代 |
|---|---|---|
| `beautiful` / `strikingly beautiful` | 权重≈0，不影响输出 | 用具体面部结构描述 |
| `anime` / `manga` / `国漫` / `仙侠` | 立绘簇，线条变硬、脸幼态 | 改用机制型词表 + 锚 |
| `cute` / `chibi` / `可爱` | Q 版 | `adult bone structure, no baby fat` |
| `mature` | 脸老 30+ | `成年骨相，颧骨结构清晰，下颌线柔和干净` |
| `large round eyes` | 黑豆眼 | 虹膜纹理 + 上眼睑褶 + 两点高光 + 圆瞳，四件齐写 |
| `narrow-lidded` 单独用 | 眯眯眼 | 必须与高光/褶线/虹膜纹理同时出现 |
| `gaunt` / `hollow cheeks` | 骷髅脸 | `full and well-fed, rounded cheeks with soft flesh` |
| `tired` / `pale` 单独用 | 眼神蔫、皮肤惨白 | `eyes open and clear and steady` |
| `黄金比例` / `八头身` | 无效，模型不解析 | 用构图参数替代（见 §4） |
| `仙女` / `俏皮` / `唯美` / `梦幻` | 立绘簇 | 换成可执行描述：`神情轻盈带笑，眉眼弯起` |
| `not a villain` 单独写 | 反而强化反派语义 | 正面写气质 + `never a scowl` |
| 长串否定（7 条以上） | 幼态化、平滑、保守 | 压到 2 条，其余改正向 |

**否定项纪律**：模型对否定词的处理不是"消除"，而是"激活+弱化"。写 `不要巨乳` 仍会把"巨乳"注入语义场。**正确做法是写正向替代**：
- ❌ `不要卡通动漫线条` → ✅ `影视级 CG 剧情画面，不是插画`
- ❌ `不要Q版、不要大头娃娃` → ✅ `成年女性骨相，颧骨结构清晰`
- ❌ `不要巨乳、不要胸部裸露` → ✅ `着装完整闭合，剪裁得体`

## 4. 构图参数（替代无效形容词）

| 用途 | aspect_ratio | 占幅 | 关键句 |
|---|---|---|---|
| 面部特写 | `1:1` | 头占 50% | `胸部以上特写，头部约占画面一半，85mm 电影镜头，极浅景深` |
| 中近景（甜点） | `16:9` | 腰以上 | `中近景（腰部以上），人物居中，机位与眼齐平` |
| 中景 | `3:4` | 膝以上 | `中景（膝部以上）` |
| 全身 | `2:3` | 85% | `全身可见从头到脚，人物占画面高度约百分之八十五，腿长，头相对身高小` |
| 场景 | `16:9` | — | `全景建立镜头，完整交代空间关系` |

**实测**：脸占画面 1/4 时五官结构清晰；全身时脸只有几百像素，必然退化成娃娃脸 → 全身图出完必须 2× 超分。

## 5. 面部公式（治无神/丑/幼态）

结构顺序：**骨相 → 眼型 → 上眼睑褶 → 虹膜与高光 → 唇 → 神态**。

### 「有神」四件齐写

```
细长杏眼，虹膜有放射状纹理、边缘深而近瞳处浅，圆形瞳孔，
上眼睑褶清晰，睫毛根根分明，瞳孔中有两点明亮高光
```

只写 `large eyes` → 黑豆眼；只写 `narrow-lidded` → 眯眯眼。

### 骨相与年龄

```
成年女性骨相，颧骨结构清晰，下颌线柔和干净，面容清丽
```
```
二十四五岁的成年青年，骨相清晰，皮肤保留真实微纹理与面部绒毛
```
**年龄必须用排除式写死**（只写数字模型会给你偏大或偏小的脸）：
```
无皱纹、无法令纹、无胡须、干净的下颌线、略带少年感的柔和骨相
```

### 皮肤

```
皮肤白皙但保留真实皮肤微纹理与面部绒毛
```
只写「白皙」→ 均匀塑料瓷皮。

### 神态（写成可指认的局部）

```
微微歪头，眉眼弯起，嘴角上扬浅笑，一侧脸颊略鼓起
```
比"俏皮""灵动"有效得多。

### 手

```
手指纤长、骨节分明、指甲淡粉
```
手是高频崩坏点，必要时单独给一句特写描述。

## 6. 中文与文字

- 画面需要出现**可辨认的汉字**时，用中文原文写进提示词（H3-Image 中文书写能力优秀）。
- 需要"有字但不可辨认"时：`filled with vertical handwritten ink marks that are not legible as characters`。
- 默认加一条排除：`画面中不要出现任何文字、字幕、水印、logo`。
