# 锚点学

> 锚点是真相，提示词是路由。这一篇讲锚怎么选、怎么排、怎么声明，以及锚会怎样"继承"和"降级"。

---

## 1. 锚到底决定什么

实测结论（见 `实测案例库.md` 案例 A）：**同一段提示词、同一个主体，只换风格锚，输出质量直接差一档**。

| 锚 | 锚的性质 | 输出结果 |
|---|---|---|
| 用户原图（最佳样本） | 影视级 CG，光比强、骨相硬 | 最高档：体积光成束、背景有纵深、脸有骨相结构 |
| 我上一轮生成的 CG 图 | 逼近但非最佳 | 次高档：光比尚可，脸偏柔 |
| 手游立绘图 | 平光、娃娃脸、飘带 | 掉档：光比平、层次薄、脸幼态化 |
| 我上一轮的"好图"当锚 | 本身偏柔 | 掉档：娃娃脸被继承 |

**关键修正**：锚不只是"画风媒介"，它会连带继承三样东西：

1. **光比**（明暗对比强度）——锚平，输出就平。
2. **骨相**（脸的年龄感、结构硬度）——锚软，输出就软。
3. **材质密度**（织物的厚薄、细节颗粒度）。

所以「选锚」= 选**脸型原型 + 光比 + 材质密度**，不是选滤镜。

## 2. 降级传递（最容易踩的坑）

**用自己的输出当锚，会沿链降级。**

```
用户原图（10 分）→ 我生成（8 分）→ 拿它当锚再生成（6.5 分）→ 再当锚（5 分）
```

这不是错觉，是锚传递的实际衰减：输出只能复制锚已有的信息，锚里没有的东西补不回来。

**铁律**：
- 风格锚 **永远选质量最高的原图**，与"最近生成"无关。
- 中间产物只能用作**身份锚**（锁脸）或**场景锚**（锁空间），**不能当风格锚**。
- 若确实只有中间产物可用，先用 `enhance_image` 2× 超分把细节补回来再当锚，或干脆换素材。

## 3. 三种锚与图序

| 锚类型 | 锁定什么 | 声明模板 |
|---|---|---|
| 风格锚 | 画风、材质、影调、颗粒 | `图1 仅作为渲染语言的风格锚：取它的材质表现力、光影层次、色彩分级与景深质感` |
| 身份锚 | 脸型、五官比例、骨相、发型 | `图1 是身份锚：严格保持这张脸与身形，不改变五官比例与骨相` |
| 场景锚 | 空间布局、陈设、光源方向 | `图1 是场景锚：保持同一空间布局与陈设，不要移动任何家具` |

**图序建议**：主体/身份图在前，风格锚在后。模型对先读到的图权重更高。

**必须显式排除锚里不要的东西**：

```
不要沿用图1的人物、面容、发型、服装、姿态与场景内容；人物与场景全部重新设计。
```

不写这句，模型会把锚的构图、人物、场景一起搬过来（实测：锚是竖幅立绘，输出也会被拽成竖幅立绘）。

## 4. 题材与锚的"语汇距离"

锚的题材与目标场景**同族**时，输出自动上一个档（模型在那个语义簇里样本密度高）。

实测：锚是「雪松林＋仙侠男」时，把主体改成「竹林女剑客」→ 输出依然保持影视CG质感；把主体改成「桃花林少女」→ 需要靠词表强拉，才回到那一档。

**异族题材的对策**（按优先级）：
1. 找一张同族题材的锚（最优解）。
2. 用机制型词表补偿（见 `影调与光.md`）。
3. 降低"图1 是风格锚"的语气，改为"图1 只作为材质与光影的参考"，减少被锚题材牵引。

## 5. 锚的挑选检查表

- [ ] 是质量最高的那张原图吗？（不是最近生成的）
- [ ] 光比是我要的？（暗部有层次还是通体平亮）
- [ ] 骨相是我要的？（硬朗/柔和/幼态）
- [ ] 材质密度是我要的？（厚重织物质感 vs 光滑塑料感）
- [ ] 题材与目标同族吗？
- [ ] 锚本身没有不需要的干扰（水印、字幕、别人的脸、过强的构图）？→ 有就先修掉或换锚
- [ ] 长宽比会不会把输出拽歪？→ 不合就显式排除锚的构图

---

## 6. 多人锚的冲突处理

- 身份锚与风格锚来自不同图时，**必须分段声明**，且身份锚在前。
- 两张锚的光比不一致时，以身份锚为准，并显式写死光位："主光来自人物左后上方"。
- 不要在一次生成里塞超过 3 张锚；实测参考图越多，归属越混乱。
- **参考图读取失败会导致整条 request 失败**（不是跳过该图），批量前先验证 URL 可达。
