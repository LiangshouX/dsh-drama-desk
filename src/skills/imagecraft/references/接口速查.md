# 接口速查（H3-Image · Connector 通道）

> 走 `connector__matrix__generate_image`，底层即 MiniMax-H3-Image 的文生图 / 图片编辑接口。
> 调用前必须先加载 `mcode-tools-master` 技能（CLI 机制）。

---

## 1. 命令形态

```bash
# 1) 本地文件 → 临时 URL（有效期 3600s）
mcode-tools upload_temp_url "<abs path>"
# → {"temp_url": "...", "expires_in_seconds": 3600}

# 2) 批量提交（一次最多 10 条 request，每条 n≤10）
mcode-tools connector call connector__matrix__generate_image --args-file "<args.json>"

# 3) 产物下载
mcode-tools get_asset_url <node_id>     # → download_url（短时有效）
```

⚠️ 生成命令用 `timeout: 600`；`--args` 与 `--args-file` 互斥；参数用文件更稳（Windows 引号地狱）。

---

## 2. 请求结构

```json
{
  "requests": [
    {
      "prompt": "…",
      "reference_images": [
        { "url": "<temp_url>", "mime_type": "image/jpeg" }
      ],
      "aspect_ratio": "16:9",
      "area": "2K",
      "n": 1,
      "output_file": "name-prefix"
    }
  ]
}
```

| 字段 | 取值 |
|---|---|
| `prompt` | 必填，≤32000 字符；**排除项写在同一字符串里** |
| `reference_images` | 1–16 张，**上传顺序 = 图号**（提示词里称「图1/图2…」）。JPEG/PNG/WebP/HEIC/HEIF，≤64MB，边长 128–8192，长边 ≤4×短边 |
| `aspect_ratio` | `auto`（默认）或 `X:Y`（1:3–3:1，X/Y 整数 1–300） |
| `area` | `1K` / `2K` / `4K`（默认 4K） |
| `n` | 1–10（每张单独计费） |
| `output_format` | 默认 `jpeg`；仅用户明确要求才用 `png` |
| `output_file` | 基础文件名，扩展名与 `-1/-2` 后缀由服务补 |

---

## 3. 硬约束

- **接口不幂等** → 重复提交＝重复扣费。付费前先落台账，失败先查台账再决定是否重发。
- **单张参考图 URL 不可达 → 整条 request 失败**。批量前先验证。
- **临时 URL 1 小时过期** → 批量作业先一次性上传全部锚，再一次提交，生成后立刻下载。
- **`area` 默认是 4K**，不写就是 4K。探针阶段显式写 `2K` 控成本。
- `output_file` 的目录部分会被忽略，只是下载时的基础名。

## 4. 成本（2K 标准版）

| 场景 | 单张 |
|---|---|
| 文生图 | ¥0.153 |
| 图片编辑（1 参考图） | ¥0.175 |
| 图片编辑（3 参考图） | ¥0.275 |

4K 限时 5 折（截至 2026-11-18）：折后文生图 ¥0.226、编辑 3 图 ¥0.261。

**策略**：探针 2K → 定稿 4K。

## 5. 其他相关工具（同一 Connector）

| 工具 | 用途 |
|---|---|
| `connector__matrix__enhance_image` | 2× 超分（PNG/JPEG/WebP，≤10MB，短边≥256，长边≤2048）。**全身图出完必做一次**，脸是最大受益者 |
| `connector__matrix__remove_image_background` | 抠图出透明 PNG |
| `connector__matrix__describe_images` | 读图问答（需 HTTPS URL，本地文件先 `upload_temp_url`） |
| `connector__matrix__reverse_image_search` | 以图搜图（排查可疑素材来源） |

## 6. 配套工具链（本地）

```bash
# 批量拼图对比（见 探针方法论.md 的脚本）
python <make_sheets.py>

# 批量下载
mcode-tools get_asset_url <node_id> | ConvertFrom-Json | % { Invoke-WebRequest $_.download_url -OutFile "<name>.jpg" }
```

环境：`conda env create -f environment.yml`（Python 3.12 + Pillow），ffmpeg/ffprobe 在 PATH 上。
