# H3 官方提示词规范（精简实操版）

> 完整官方文档见 <https://huggingface.co/MiniMaxAI/MiniMax-H3/tree/main/docs>
> 本文件是实操提炼 + 本项目实测补充。标注「实测」的部分来自 2026-11-01 的 5 镜验证。

---

## 1. 两种格式

### 1.1 基础模式（T2VA / I2VA / FL2VA / L2VA）

三段式，顺序固定：

```text
integrated_multimodal_description: [Shot 1] ...

overall_soundscape: ...

non_diegetic_music: ...
```

`I2VA` / `FL2VA` / `L2VA` 需在开头加对齐说明行，后接一个空行：

```text
I2VA:
For the target video, at 0.00 seconds into the target video, <Picture 1> (from [Shot 1]) is fully referenced.

FL2VA:
How the reference pictures align with the target video — Picture 1 (from Shot 1) aligns with the 0.00-second mark of the target video; Picture 2 (from Shot N) aligns with the S.SS-second mark of the target video.

L2VA:
How the reference pictures align with the target video — <Picture 1> (from [Shot N]) aligns with the S.SS-second mark of the target video.
```

`N` = 实际最后一个镜头序号，`S.SS` = 有效时长，**保留两位小数**。

### 1.2 完整参考模式（六段式）

用于 `reference_images` / `reference_videos` / `reference_audios`：

```text
subject_definitions:
summary:
retention_analysis:
detailed_description:
overall_soundscape:
non_diegetic_music:
```

**顺序不可调换。** 除对白、歌词、可见文字外，全部用英文书写。

## 2. 标签体系

| 标签 | 含义 |
|---|---|
| `<Subject N>` | 可复用的可见内容（人、物体、场景、风格、动作、特效） |
| `<Picture N>` | 具体的一帧图、关键帧、首尾帧、分镜参考图 |
| `<Video N>` | 整段视频编辑、续接源、时间/机位/剪辑结构来源 |
| `<Audio N>` | 复制或引用的音频，编号体系独立于视频 |

**规则**：

- 每个标签在所有段落中保持**同一个含义**
- 每个标签在 `retention_analysis` 中**各占一行**
- `<Picture N>` 必须对应真实提供的参考图资产
- 只定义主体的图片 → 在 `<Subject N>` 定义内部引用 `<Picture N>`，
  **不要**单独建 Picture 条目和 retention 行
- 声音标签不等于视觉主体：`<Audio N>` 的声音不会让发声者变得可见

### 保留标记（只能用这些）

- 视觉：`fully_preserved` / `partially_preserved` / `attribute_transfer` / `weak_reference`
- 音频：`fully_copy` / `partially_copy` / `reference` / `weak_reference`

`attribute_transfer` 只用于特征被应用到**另一个**可识别主体。
同一主体的身份与属性保持用 `fully_preserved` / `partially_preserved`。

## 3. 核心写作规则

### 3.1 结构性硬要求

| 规则 | 说明 |
|---|---|
| `[Shot 1]` 必须是 `integrated_multimodal_description:` 后的**第一个词** | 基础模式强制；完整参考模式的 `detailed_description` 允许前置 1-2 句风格描述 |
| 不要在提示词里写时长和画幅 | "a 15-second film" / "through 15.00 seconds" / "in 16:9" 都是错的，用 API 参数传 |
| 基础模式不写全局时长与比例标签 | 用它们来规划节奏与构图，但不写进提示词正文 |

### 3.2 镜头与时间线

- `[Shot 1]` 无时间戳；后续镜头用递增序号 + 严格递增的切点时间
  例：`[Shot 2] At 00:03.500, the camera cuts to ...`
- N 个镜头的线性序列 = N-1 个切点。**不要把每个片段都叫切点。**
- 一个切点必须带来新的主体、空间、状态、视角或时间信息。
  小的构图变化用**运镜**表达，不要用切点。
- 每个镜头：**一个主动作 + 一个主运镜**。辅助运动要配合主节拍，不能与之竞争。
- 保持可见的**因果锚点**贯穿镜头（当序列是一个形变过程时）。
  抽象影像选 2-3 个反复出现的母题（光点、信号路径、半透明平面）并复用，
  而不是堆砌互不相关的物体。

### 3.3 运镜词汇表（直接用，不要自造）

```
Zoom In/Out · Push In/Pull Out · Pan Left/Right · Truck Left/Right
Tilt Up/Down · Pedestal Up/Down · Arc Shot · Tracking Shot · Static Shot
Shake Slightly/Strongly · POV · Roll Clockwise/Counterclockwise
```

幅度和速度只在有意义时加：`with small/large amplitude`、`at slow/fast speed`。
**实测**：写 "slow Push In with small amplitude" → 确实缓慢推近。

### 3.4 说话人、对白、可见文字

- 按**实际发声顺序**分配 `(S1)` `(S2)`，跨镜头复用同一 ID
- 非发声角色不给 speaker ID；同时说话可用 `(S1,S2)`
- 说话人首次出现时建立稳定的视觉/听觉身份
- **speaker ID 和语气放在 `<d>` 外面**，`<d>` 里只放语言标签和台词：
  ```
  <Subject 1> (S1) says: <d>[Chinese] 这条街，今天也没人。</d>
  ```
- 台词、歌词、可见文字**逐字保留**，不翻译、不改写、不改标点
- 可见文字用**英文双引号**：`"[PRODUCT TITLE]"` 形式。
  缺失时用方括号占位，不要臆造品牌、型号、口号
- 台词跨切点：用 `<scenetrans>` 连接两处并说明音频跨切延续；
  语音被截断用 `<cutoff>`

### 3.5 画内音 vs 画外音 ⚠️（实测关键）

**画外音（voiceover）官方写法**：

```text
<Subject or speaker> (S1) says in an off-screen voiceover: <d>[Language] Exact words.</d>
Immediately after the complete <d> block, state that the corresponding on-screen character's lips remain completely closed.
```

> **实测警告**：这段里的 "lips remain completely closed" 是明确闭唇指令。
> 四条提示词全部用了这段，SH01/T1 口型不明显，T2/T3 **彻底没有口型**。
> **要口型就不能用这段写法。**

**画内音（口型）写法**：

```text
<Subject 1> (S1) says: <d>[Chinese] 台词。</d> His lips move clearly with the words as he speaks.
```

- 不出现 "off-screen voiceover"
- 不出现 "lips remain completely closed"
- 明确描述嘴唇随说话动作

**选择原则**：AI 短剧默认用**画内音**；画外音只用于真正的旁白/内心独白。

### 3.6 声景分层

| 段落 | 内容 | 禁忌 |
|---|---|---|
| `overall_soundscape` | 1–4 句英文：环境音、物理动作声、非语言人声 | 不重复对白/歌声/剧情内音乐 |
| `non_diegetic_music` | 1–3 句英文：仅观众听见的配乐（乐器、速度、节奏、力度） | 不描述情绪或叙事功能 |

- 只有明确要求完全静音时才用 `N/A`
- 音质动作音要与时间线一致：描述听到的滚动、撞击、沉降，
  **不要**添加时间线里没有的加速/减速/额外原因
- `non_diegetic_music` 用定性速度（除非用户给了确切 BPM）

## 4. 关键帧路径

| 模式 | 写法要点 |
|---|---|
| **I2VA** | 建立参考的风格、构图、主体身份、服装、颜色、道具、固定环境几何 → 然后 `首帧锚定 → 动作起点 → 连续发展 → 结果/反应`。当动作改变时，位置、姿态、道具状态是**变化的状态**，不能同时描述成不变 |
| **FL2VA** | 描述姿态、物体状态、机位、构图、光线中**可观察的中间变化**。除非用户明确要求切点，优先单镜头；结尾落在尾帧图上 |
| **L2VA** | 推断一个兼容的早期状态，给出明确的过渡路径，逐渐收敛到给定尾图。物理驱动变化用 `成因 → 接触 → 材质反应 → 沉降`；动作要与可见力一致 |

---

## 5. 长度参考

- 基础模式：视复杂度而定，无硬性上限（上限 7000 字符）
- 完整参考模式：`detailed_description` 通常 **350–500 英文词**；
  对白密度和源视频复杂度优先于机械的字数目标

## 6. 本项目补充（实测）

- **参考图声明虽非必需，但建议保留**（T2 无声明也正确，但有声明时跨镜头一致性更可控）
- **互斥状态混用时必须写消歧句**（T3 验证有效）
- **主体定义与描述不得矛盾**（唯一真凶，见 `实测结论.md` 第 2 节）
- **道具贴纸可能被"搬家"** → 道具特写单独准备清晰参考图

### 6.1 提交前质量闸（R17，2026-11-12 复检）

**「除对白、歌词、可见文字外全部英文」是硬规范**，容易漏的是
`overall_soundscape` / `non_diegetic_music` —— 它们也是正文。
2026-11-12 复检发现 45 条提示词的声景**全部**是中文（「近景：…；远景：…」），
肉眼通读时根本不会发现，必须机器查。

```bash
python workspaces/<work-id>/prompts/check_prompts_v2.py   # 退出码非 0 不可提交
```

机器查：禁词、六段式结构、中文残留（台词除外）、双句点、可见文字引号。
**机器查不到、必须人眼过一遍**的三类硬伤：

| 问题 | 症状 | 改法 |
|---|---|---|
| 主体指错 | `<Subject N> is the subject of this shot` 指向环境/道具 | 指向本镜真正在动的主体 |
| 口型性别错 | 女角色写成 `His lips move clearly…` | `Her lips move clearly with the words as she speaks.` |
| 模板残句自相矛盾 | `the same clothing` 与 `with the outer jacket off` 同句 | 删残句，状态用正向描述写清 |

配套：`non_diegetic_music` 只在明确要求完全静音时写 `N/A`；
音色描述词从 `characters.json` 的 `voice_desc` **逐字**复制（R9）；
画外音写 `Off screen, X (S) speaks: <d>…</d>`，**不写 voiceover、不写闭唇句**（R3）。
