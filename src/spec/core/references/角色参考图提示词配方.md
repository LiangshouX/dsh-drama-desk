## 0. 上一版为什么失败（根因，不是细节问题）

| 症状 | 上一版做法 | 真实原因 |
|---|---|---|
| 人物一致性崩坏 | 用大段英文逐字复述「同一张脸、鹅蛋脸、细长杏眼……」，靠 `image_url` 单图锚定 | **文字描述锁不住脸。** 同一段文字重新采样 = 另一个概率分布 = 另一个人。 |
| 场景割裂 | 每张场景各自写「赛璐璐 + 透明水彩」，各自生成 | **文字画不出画风。** 每次采样对「赛璐璐」的理解都略有偏差，20 张 = 20 种偏差。 |
| 审美差 | 靠加形容词（`beautiful`、`strikingly beautiful`、`refined`） | 抽象审美词权重接近零；**没有参考图时，模型只能输出训练分布的平均值**——那个平均值就是「平庸」。 |

**一句话**：上一版把「参考图」当装饰、把「提示词」当唯一真相。实测证明**参考图才是真相**，提示词只负责说明「从每张参考图里取什么、不取什么」。

## 1. 新架构：三图分工（本次实测的核心）

H3-Image 图片编辑接口支持 **1–16 张参考图**，按上传顺序编号为「图1 / 图2 / …」。每张图**只承担一个职责**，并在提示词里明确声明取什么、不取什么。

```
图N = 身份锚（Identity Anchor）  → 角色的脸/发型/身形。只有 1 张，且必须是该角色最满意的脸。
图N = 风格锚（Style Anchor）      → 全片统一的画风、线条、上色、配色、纸面肌理。全项目共用同一张。
图N = 场景锚（Scene Anchor）      → 同场景的其他时间/角度。用「白天的店内图」去锁「夜里的店内图」。
```

### 图序约定（写死在提示词里，别改）

| 用途 | 图1 | 图2 | 图3 |
|---|---|---|---|
| 角色全身/面部 | 该角色定妆脸 | 风格锚 | — |
| 角色多状态 | 该角色定妆脸 | 风格锚 | — |
| 场景（首张） | 风格锚 | — | — |
| 场景（同场景变体） | 场景锚 | 风格锚 | — |
| 道具 | 风格锚 | — | — |

### 风格锚的选择（本项目已定）

**`refs/style_anchor_alley.jpg`（老街巷口）是全片风格锚。** 选它的原因：它是上一轮 20 张里唯一一张用户给出 8 分（审美、布景都好）的图——它是**用户审美已经被验证过的锚点**，比任何文字描述都可靠。

> ⚠️ 风格锚本身是 9:16 竖幅。用它当参考图时**必须在提示词里显式排除它的构图和内容**，否则模型会把竖构图和巷口景物带进角色图：
> `不要取图1里巷口的任何景物、招牌、车辆，也不要取它的竖构图。`

> ⚠️ **锚点路径必须是不可变的**（2026-11-14 修正）。`gen_refs.py` 曾把风格锚指向
> `refs/scene_alley_cn.jpg` —— 那是一条**会被批次重做覆盖的可变路径**。后果有三：
> ① 20 张参考图实际对齐的不是上面这张冻结锚，而是 00:18 写入的第一批生成图；
> ② 第二批又覆盖了该路径 → 脚本重跑会锚到第三张图，**不可复现**；
> ③ `refs/scene_alley_cn.jpg` 本身是**片内场景参考图**（老街巷口），与风格锚职责不同。
>
> **现在**：
> - 风格锚 = `refs/style_anchor_alley.jpg`（冻结，用户 8 分验证）
> - 身份锚 / 场景锚 = `refs/anchors/*.jpg`（原 `.tmp/probe*/` 探针产出，2026-11-14 归档入库）
> - 全部锚点的 sha256 钉在 `refs/anchors/MANIFEST.json`
> - 所有生图脚本提交前调 `anchor_manifest.verify()`，锚被替换/丢失即报错退出
>
> **不要用 `.tmp/` 下的任何路径当锚**——它被 `.gitignore` 忽略，清一次 tmp 就断链。

## 2. 提示词结构（五段，顺序固定）

```
① 参考图职责声明   「图1 是…身份参考：严格保持…不要改变他的长相。图2 只作为画风参考：取…不要取…」
② 画风工艺段       赛璐璐上色 + 透明水彩 + 松软线条 + 低饱和暖调 + 排除项
③ 人物/场景主体段  脸 / 体型 / 服装 / 陈设（具体到每一件东西）
④ 神态与姿态段     看哪儿 + 眼睛开合 + 嘴角 + 手在做什么
⑤ 构图与禁令段     画幅 + 占幅 + 背景 + 不要文字/水印/边框
```

**关键**：① 必须在最前面。模型先读到「图1 是脸、图2 是画风」，后面的文字才有归属。

### 画风工艺段（可直接抄，逐字复用）—— v2.1 版（2026-11-15，以「二次元立绘」达标图为过关线）

```

按实拍电影布光：有方向且画内可见的主光（午后斜射的暖阳、窗光、裸灯泡、街灯），
发丝与肩线上的暖色轮廓光，空气里有浮尘。
冷调环境，暖色光：墙、货架、地面与远处的暗部一律是青灰、蓝灰、藏青与靛紫的冷调；
只有被光照到的地方才转成暖赭石与古金，冷暖之间有一条清楚的分界线。
饱和通透，暗部是通透的靛蓝与紫灰。干净清爽，有生活气。
不要照片写实、不要3D渲染、不要厚涂笔触堆积、不要欧美卡通、不要绘本插画、不要脏旧做旧、不要平光、不要整体暖调。
```

> ⚠️ **v2.1 → v2.2 的变更（2026-11-15）**：色域从「暖色主导」改为「**冷调环境 + 暖色光**」。
> 依据：三张达标参考图的整体冷暖（R−B，负=冷）是 **−47.0 / −0.8 / −28.8**；
> v2.1 的 6 张锚是 **+31 ~ +54**，且**暗部同样是暖的**（+5.6 ~ +18.7）。
> 冷暖差（亮−暗）其实两边都大——**问题不是反差不够，是整张都暖**。
> 「暖色主导」这条宪法要求整张图暖，是"闷"的直接原因，已废止。
> 见宪法「冷暖分离」条款与 `VERSIONS.md`。

> ⚠️ **v2 → v2.1 的变更**（2026-11-15，实测确立；对照 `.tmp/.example/二次元立绘/MiniMax-H3-Image.png`）：
> **只加了一句「勾线极细」**，输出质量却质变——脸从"欧美写实卡通脸"变成"二次元美型脸"。
> 量化读数（P1x 组 2/2 达标、组内极差仅 **0.004**，为全部探针组最稳）也印证了这一点。
> **线条粗细是"精致度"的总开关**，而它此前从未被写进提示词。

**中英文结论**：同一提示词，中英文产出质量**没有显著差异**。旧流程坚持英文并无收益，可按需混用（**画面里要出现的中文必须用中文原文**）。

## 2.1 参考图制品形态（v2 关键变更）⚠️

**参考图不是设定表，是美图。**

| | v1（已作废） | v2（当前） |
|---|---|---|
| 角色图形态 | 全身正面站立 + 胸像正面 + **纯暖白背景** | 同上构图，但**带侧逆光、暖调、浅景深、真实环境** |
| 实测平均饱和度 | **0.051–0.170**（接近白纸） | **≥ 0.28**（硬下限） |
| 实测均亮度 | 188–220 | 98–138 |
| 定妆脸 | 平光白底证件照 | **从零重建**：纯文字按面部公式生成的第一张定妆照（带光带环境），它自己就是身份锚 |
| 风格锚 | 一张场景图（只锁光不锁人） | **一张人物 + 光 + 环境都到位的成品图**（背影，避免身份渗漏） |

**为什么必须这样**：imagecraft A1 ——「锚点决定成品的天花板。锚里有什么，输出就有什么，
**包括画风、材质、骨相、光比**」。设定表按行业惯例是**功能性文档**（传递信息，不是传递美感），
拿它当锚＝**把成片压成设定表级的平光**。这条与提示词写法无关，是制品选型问题。

### ⚠️ v1 锚点一律不得沿用（2026-11-15 实测）

曾计划「用 v1 定妆脸锁身份、用 v2 重做光」，**经体检否决**：
v1 的 5 个锚点饱和度只有 **0.138–0.263**，全部低于 0.28 门槛，且是平光白底——
**拿它们当锚，等于把"平"直接继承给 v2。**

脸与空间布局本来就有文本规格（`characters.json` 的 `appearance` ＋ 本文 §3 面部公式；
场景布局见 `角色视觉设计v3.md` §五），所以：

> **v2 锚点从零重建。第一张定妆照纯文字生成，它自己就是新的身份锚。**
> **锚链只有一个根，且是美的那个。**

**验收**：参考图入库前跑 `python tools/image_qc.py --dir <目录>`，
4 项判废（饱和/明度/低饱和区/色丰）全过才算合格，**< 0.28 直接重出**，不要靠提示词补救。

> **审图一律用读数，不用拼图。** 大尺寸多脸拼图会被模型输入审核判为敏感并**永久卡死会话**
> （每轮重放历史、每轮被拒、重试无用）。必须看图时由**人**直接打开原图，
> 任何喂给 `read_image` 的图**最长边必须 ≤ 1200px**。见 `imagecraft/references/探针方法论.md` §3.0。

## 3. 面部公式（治「无神」与「丑」）

结构顺序固定：**脸型 → 眼型 → 上眼睑褶 → 虹膜与高光 → 唇 → 神态**。

### 「有神」的三要素（缺一即死鱼眼）

1. **两点高光**：`two small bright catchlights in each pupil`
2. **虹膜放射状纹理**：`irises with radial texture, darker at the rim and lighter toward the pupil`
3. **上眼睑褶**：`a crisp upper eyelid crease, individual lashes clearly separated`

> 只写 `large eyes` 会得到黑豆眼；只写 `narrow-lidded` 会得到眯眯眼（上一版 `aling_anchor_full_cn` 的 -10 分死穴）。**必须三者齐写。**

### 瞳孔形状（防「活死人」）

```
round pupils rather than vertical slits
```

上一版 `aling_anchor_face_cn` 的「竖瞳 + 黑眼圈 = 活死人」，根源是没写瞳孔形状。**这一句必须常驻。**

### 反向否定（有效，但别滥用）

```
No blush, no baby fat, no childish roundness.     ← 治幼态
not gaunt, not hollow-cheeked, not sinister        ← 治反派/骷髅
not a villain, never a scowl                      ← 治脸谱化
```

### 角色配方（实测验证）

**主角 · 十八岁少女（主角）**
```
Her face is a clean long oval with a slender jawline and a narrow chin.
Her eyes are large, long and narrow-lidded elegant almond eyes with slender
dark brown irises showing radial texture, darker at the rim and lighter toward
the pupil, round pupils rather than vertical slits, a crisp upper eyelid
crease, long straight eyelashes, and two small bright catchlights in each pupil.
Her eyebrows are fine, straight and elegant.
Her nose is small and straight with a delicate bridge.
Her lips are small, lightly defined and softly closed, with a clean lip line.
Her skin is luminous and transparent with an even natural tone.
```
> 想要更甜 → `softly oval face with full but not babyish cheeks` + `large and clear eyes, bright and open` + `a faint natural peach flush` + `eyes soft and slightly lowered`。
> 想要更成熟 → `MATURE and ARISTOCRATIC beauty rather than a cute one` + `clearly an adult teenager's bone structure, never a childlike round face` + `No blush, no baby fat, no childish roundness`。

### 面部精度条款（v2.1，2026-11-15 实测确立）—— 所有角色通用

> 实测：同一张脸型公式，加上这一组"精度条款"与「勾线极细」后，
> 脸从"欧美写实卡通脸"变成"二次元美型脸"，组内极差从 0.041 降到 **0.004**。

```
眼睛细长而平静，眼型偏平、长度大于高度，眼白清晰但不大；
眼神安静专注，瞳孔放松，不睁大也不眯起；
睫毛极细，每一根都画得清清楚楚，像细密的针尖；
眉毛细得像一根一根画出来的，中间淡、眉尾收尖；
鼻子只用极少的几笔表示，鼻梁上不画线，只在鼻尖点一小点淡影；
嘴唇只有一条干净的线与一点点厚度，唇线清晰，没有多余的轮廓；
皮肤通透有血色，脸上没有任何多余的线条
```

- 这套条款描述的是**"精致度"**，不是"长相"。长相由角色自己的面部公式决定，两者叠加。
- 与「勾线极细」是**一组**：线条粗细不统一时，再精细的五官也会被粗线吃掉。

> ⚠️ **不要写「眼睛很大 / 眼白占三分之一以上」**（2026-11-15 实测踩坑）。
> 该写法会让模型把眼睛画成卡通式大眼 + 大量眼白 → 人物读起来是**惊愕**而不是平静，
> 正是危险词表里 `large round eyes → 黑豆眼`、`cute/chibi → Q版` 的同一类问题。
> 要"眼睛大"就写**眼型**（细长杏仁眼 / 眼尾平直），不要写**尺寸**。
> 同组实测：去掉尺寸描述后，脸从"惊愕大眼"回到自然杏仁眼，饱和度 0.413 → 0.314。
> **精致度来自线条与睫毛，不来自眼睛变大。**

**店主 · 六十岁老人（结构性对手，不是反派）**
```
His face is full and well-fed: rounded cheeks with soft flesh under them, a broad
face, a full jaw, no sunken cheeks, no hollow temples, no gaunt look.
His eyes are deep-set but calm and steady, resting half lowered on the objects in
his hands, with fine lines at their outer corners and gentle lower lids.
His lips are thin, closed, with a kindly neutral line, the corners very slightly down.
He looks dignified, tired and gentle, never angry, never a scowl, never a villain.
```
> **「not gaunt」+「rounded cheeks with soft flesh」是必写项。** 只写「骨相明确」会得到骷髅脸。

**哥哥 · 二十四五岁青年**
```
a YOUNG Chinese man in his mid twenties, twenty-four or twenty-five years old.
He must read as a young man, not a man in his thirties or forties: smooth
unwrinkled skin with no forehead lines, no crow's feet, no nasolabial folds,
no facial hair, no beard or stubble, a soft youthful jawline, plump cheeks.
```
> **年龄必须用「排除式」写死。** 只写 `24-26 year old` 会出三十五岁的人（AGENTS.md 记录的「参考图偏少年相」问题在 H3-Image 上反过来出现——默认偏成熟）。同理，店主要显式写 `60 years old` 而非 `58-62`。

**小贩 · 四十多岁壮汉**
```
a broad round friendly face with full cheeks and a soft heavy jawline.
Thick dark eyebrows. Small kind eyes narrowed into gentle smiles with deep
creases at their outer corners, small dark-brown irises with catchlights.
A broad slightly bulbous nose. A wide courteous sheepish grin, lips full and soft.
Clean-shaven with only a soft shadow of stubble.
```
> 加 `stocky and solid working man`、`not thin`、`not a pervert` 防猥琐化。

## 4. 危险词表（H3-Image 实测）

| 词 | 后果 | 替代 |
|---|---|---|
| `beautiful` / `strikingly beautiful` | 权重≈0，不影响输出 | 用具体面部结构描述 |
| `anime` / `manga` | 萌系少年漫画，线条变硬 | `hand-drawn 2D animated feature` |
| `cute` / `chibi` | Q 版 | `not chibi`、`adult teenager's bone structure` |
| `mature` | 脸老 30+ | `MATURE and ARISTOCRATIC`（修饰 beauty 而非年龄） |
| `large round eyes` | 黑豆眼 | 三要素齐写（见 §3） |
| `narrow-lidded` 单独用 | 眯眯眼（-10 分） | 必须与高光/褶线/放射纹理同时出现 |
| `gaunt` / `hollow cheeks` | 骷髅脸 | `full and well-fed, rounded cheeks with soft flesh` |
| `tired` / `pale` 单独用 | 眼神变蔫、皮肤惨白 | `eyes open and clear and steady` |
| `apron`（尤其配深色） | 女仆/中年妇女感 | 配合「壮汉」体型一起写 |
| `not a villain` 单独写 | 反而强化反派语义 | 正面写 `dignified, tired and gentle` + 负向 `never a scowl` |
| `backroom` / `old room` | 自动出民国/旧式 | 写具体当代物件（铁架床、塑料衣柜、缝纫机、裸灯泡） |
| `traditional Chinese` / `新中式` / `国潮` | 海报味、符号堆砌 | 只写具体物件 |
| `flat lighting` / `even lighting` / `uniform lighting` | 平光 → 饱和度崩塌（v1 实测 0.05–0.17） | 写方向性主光 + 轮廓光 + 反弹光 |
| `no cast shadow` / `shadowless` | **否定句反向激活**（同 R3 口型坑） | 直接不写；不要用否定表达"无影" |
| `人物设定图` / `character design sheet` | 带入"平、白底、站桩"的品类先验 | 写 `电影质感` / `cinematic`，不声明是设定表 |

### 「劳动痕迹」词是个陷阱（2026-11-11 实测踩坑）

写劳动人民时，很容易顺手写上「手被碱水泡得发红」「指甲缝嵌着豆渣」「满是油污」这类词。
**模型会把它们放大成灾难级脏污**，实测后果：

| 写法 | 实际产出 |
|---|---|
| `双手被碱水泡得发红` | 通红的冻伤手（用户：「这夏天又不是冬天冻得」） |
| `指甲缝嵌着豆渣` | 黑洞甲缝 |
| `围裙有豆腐渍与水痕` | 整条围裙油腻发黑 |
| `刮净只留青茬` + 整体未约束 | 蓬头垢面、油光满面 |

**规律**：脏污类词没有「轻微」这个档位。要表达「劳动的痕迹」，必须**指定部位 + 指定幅度 + 指定颜色**：

```
仅仅是指尖和指关节处有一层很淡的粉色——那是被豆浆和碱水泡久了的痕迹，
非常轻微，像晒过太阳的手背那样自然。双手是干净的，指甲剪得整齐，
甲缝里没有豆渣没有黑泥，手上没有伤口没有红肿没有皲裂。
```

**同时给「整体气质」兜底**——这是最有效的一句：

```
干净利索、讲究卫生、质朴但不邋遢。他是个爱干净、做事仔细的小生意人，
衣服旧但是洗得干净。
```

> **质朴 ≠ 邋遢。** 小贩、卖早点的、扛苦力的，观众要买他做的东西——
> 画邋遢等于画「没人愿意买」。脏 = 贬义，朴 = 中性，**「旧但干净」才是正解**。

## 5. 反向否定清单（通用，可直接抄）

> ⚠️ **按层用，不要整段照抄到每张图。**（2026-11-14 修订，细则见 `.agents/skills/imagecraft/SKILL.md` A5）
>
> | 层 | 上限 | 用哪几条 |
> |---|---|---|
> | 面部层 | **0 条** | 不放任何否定。面部公式全是正向描述；负向意图改写成正向形态 |
> | 媒介层 | **≤2 条** | 从下面清单里挑**最致命的两条**（通常是「不要照片写实」「不要3D渲染」），其余删掉；同层正向词写足 |
> | 格式层 | 可放宽 | 「不要文字／不要水印／不要边框／不要其他人物／不要人手」——低歧义构图约束，本项目实测每张带 3–4 条未出问题 |

媒介层（画风工艺段）：

```
不要照片写实、不要3D渲染、不要厚涂笔触堆积、不要欧美卡通、不要绘本插画、
不要脏旧做旧、不要Q版、不要大头娃娃、不要海报感、不要文字、不要水印、不要边框、
不要其他人物、不要人手
```

**年代感靠可指认的物件，不写「年代感」本身。** 想要「当代中国南方旧城」，就写：搪瓷缸、玻璃瓶、水泥方格货架、铝合金推拉窗、卷帘门、空调外机、塑料方凳、白色编织袋、脚踏缝纫机、裸灯泡、香樟树。

**要排除的旧物**（每张场景图都加）：草席、竹床、蚊帐、搪瓷痰盂、煤油灯、热水瓶、算盘以外的民俗摆件、土坯墙、火炉子、灰泥房。

## 6. 构图

| 用途 | aspect_ratio | 占幅 | 关键句 |
|---|---|---|---|
| 全身 | `2:3` | 85% | `Full body visible from head to feet, the figure filling about eighty-five percent of the frame height` |
| 面部 | `1:1` | 50% | `chest-up close-up, the head filling about half the frame, shoulders visible` |
| 场景 | `16:9` | — | `a wide establishing view that shows the whole spatial relationship` |
| 道具 | `1:1` | 70% | 道具居中，浅暖灰背景 |

- 面部特写写 70–75% 会把脸顶满画面，显廉价。**50% 是甜点。**
- 全身图写「八头身」无效，靠 **2:3 + 占幅 85% + `legs are long, the head is small relative to the height`**。
- 场景图要**全局视角**（`a wide establishing view`），否则同一场景的不同镜头会各自发明空间关系。
- **v2 变更：角色图的背景不再是「纯暖白」**。必须是**带光的环境**——
  侧逆光打在身上、背景是有虚化的真实空间（浅景深）。纯色背景的角色图是 v1 审美平庸的第一推手，
  详见 §2.1。定妆脸尤其重要：它是全片身份与画风的共同入口，**必须是美图，不是证件照**。
- **v2.1 变更：背景要压暗，主体是画面里最亮的部分**（2026-11-15 实测）

  达标图的**主体/背景明度差 = +26.9 / +21.9 / +9.6**；
  v2 的产出只有 **+5.3**（主体与背景同调，人物"融"在背景里，不跳）。
  加上"背景整体压暗压冷"后，实测做到 **+47.6**。

  ```
  背景整体压暗压冷，深处沉入暗调；
  身后的货架、器物化成柔和的圆形散景光斑，斑块分明，不是一团模糊的暖雾；
  她是画面里最亮的部分，脸与肩上的暖光最亮，身后比她暗一档。
  ```

  ⚠️ **但这条不稳定**：单独立臂实测 2 张落在 0.390 / 0.235（极差 0.155，> 0.10 不可信线）。
  与「面部精度 + 勾线极细」合用时才稳定（2/2、极差 0.004）。**先修脸，再压背景。**
- **v2 变更：道具图背景也带光**——浅暖灰可以，但要有方向性光影，不要死平。

## 7. 工作流（实测验证）

```
① 定妆脸（1:1）
   参考图 = [风格锚]，纯文字描述脸 → 出 3 张挑 1 张
② 身份锚确认
   把选中的定妆脸存为 refs/<char>_face_anchor.jpg，这是该角色唯一的身份真源
③ 角色其余全部图
   参考图 = [该角色定妆脸, 风格锚]，提示词声明各自职责
④ 场景首图
   参考图 = [风格锚]，纯文字描述陈设
⑤ 场景变体（夜间/其他角度）
   参考图 = [场景首图, 风格锚]，提示词强调「同一房间、同一个柜台、同一组货架，不要移动任何家具」
⑥ 道具
   参考图 = [风格锚]
⑦ 全量验收
   横向并排看：脸型漂移 / 画风漂移 / 场景漂移 / 时代穿帮 / 中文乱码
```

### 多状态处理

同一角色的不同服装状态**不靠文字切换，靠「同一张脸 + 不同服装描述」**。身份锚不变，服装段换掉。

> **踩过的坑**：`anchor` 状态写「眼下淡紫影」→ 模型画成浓紫眼影（不像熬夜，像化妆品）。修正写法：
> `a very faint and barely-there cool grey shadow on the skin under her eyes — not dark circles, not eyeshadow, not bruising, not makeup`。

### 中文书写

**需要画面出现中文时，用中文原文写进提示词**（实测确认 H3-Image 中文书写能力优秀）：
- 旧契上的「主角 哥哥」+ 朱红线 → **完全正确写出**，含朱砂印。
- 但**账本内页**要求「写满名字」→ 出乱码汉字（模型试图逐字写却写不对）。
  → **解法：不要要求可辨认的文字。** 改写为 `filled with vertical handwritten ink marks that are not legible as characters`。需要出现具体汉字时才写明原文。

## 8. H3-Image 接口速查（Connector 通道）

走 `connector__matrix__generate_image`（`mcode-tools connector call`），底层即 H3-Image 的文生图/图片编辑接口。

```json
{ "requests": [ { "prompt": "...", "reference_images": [ {"url": "<temp_url>", "mime_type": "image/jpeg"} ],
                  "aspect_ratio": "2:3", "area": "2K", "n": 1, "output_file": "name" } ] }
```

| 项 | 值 |
|---|---|
| 参考图 | 1–16 张，上传顺序 = 图号 |
| `aspect_ratio` | `auto`（默认）/ `X:Y`，1:3–3:1 |
| `area` | `1K` / `2K` / `4K`（默认 4K） |
| `n` | 1–10 |
| 输出格式 | `jpeg`（默认）/ `png` / `webp` |
| 文本上限 | 32000 字符 |

**本地文件先传临时 URL**：
```bash
mcode-tools upload_temp_url "<abs path>"     # → temp_url，有效期 3600s
```
**下载产物**：
```bash
mcode-tools get_asset_url <node_id>          # → download_url
```

⚠️ **临时 URL 1 小时过期**。批量作业要先全部上传，再一次性提交；生成后立刻下载入库。
⚠️ **接口不幂等**，重复提交 = 重复扣费。批量前先写台账。
⚠️ 单个参考图读取失败会**整条 request 失败**，不是只跳过该图。批量前先验证 URL 可达。

## 9. 验收清单（逐条人眼过）

- [ ] 与该角色定妆脸并排，脸型/眼型/唇形是否还是同一个人
- [ ] 眼睛：眼白清晰？上眼睑褶？两点高光？虹膜纹理？瞳孔是圆的（不是竖缝）？
- [ ] 画风：与风格锚并排，线条粗细、上色方式、纸面肌理是否一致
- [ ] 场景：与场景锚并排，家具陈设位置是否未变？是否仍是同一个空间？
- [ ] 时代感：有无草席/痰盂/煤油灯/民国/农村等穿帮
- [ ] 比例：全身图腿长吗？头相对身高小吗？
- [ ] 中文：出现的汉字对吗？不该出现文字的地方有没有乱码？
- [ ] 手：正常大小吗？有没有多指/糊成一团？
- [ ] 神态：写实到「看哪儿 + 眼睛开合 + 嘴角」了吗？
- [ ] 数值年龄：说二十五岁的看起来像二十五岁吗？说六十岁的像六十岁吗？

## 10. 禁区

- ❌ 和服、袴、木簪、鸟居、纸门、榻榻米、庙会、浮世绘式构图
- ❌ 「中国风」「国潮」「新中式」「Oriental」这类**风格标签词**——只写具体物件
- ❌ 真实品牌 logo、公众人物、真实地名、政治宗教符号
- ❌ 厚涂笔触堆积、写实解剖脸、冷灰蓝阴影、CG 渲染感、边框装饰、恐怖化处理
- ❌ 把店主画成反派；把超现实拍成恐怖
- ❌ 要求画面写出「可辨认的汉字」却不给出确切字面（会出乱码）
