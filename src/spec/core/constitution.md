# 创作宪法

> 项目级、跨阶段生效的风格与禁区约束。所有阶段技能在开工前都要读它。
> 覆盖栈：作品内 `workspaces/<work-id>/constitution.md` 优先于本文件（作品级覆盖项目级）。

## 叙事

- 视角：第三人称限知（跟随主角），不用全知、不用第一人称混切
- 时态：过去时叙述
- 密度：一场只推进一个主要动作；不并行多线

## 题材与禁区

- 尺度：PG-13，不出现血腥特写、不出现未成年人受伤害的细节
- 现实主义：不做超自然设定；超现实元素必须前后自洽并有代价
- 不使用真实品牌名、真实公众人物、真实事件当事人

## 角色

- 数量：单集不超过 4 个有台词角色
- 每个角色必须有一个可被镜头拍到的**行为特征**（不是性格形容词）
- 主角的缺陷必须可演，且在故事中被触发至少一次

## 台词

- 口语短句，单句不超过 25 字；不用书面语长句
- 不解释设定：角色不说"因为我从小……所以……"
- 情绪靠动作与停顿承载，不靠形容词堆叠
- 每个角色说话方式可区分（句长、用词、是否用敬语）

## 视觉

- 色调：**饱和通透**，冷暖对比明确。「低饱和」是可选风格而**不是默认**——低饱和叠加平光就是灰平
- **冷暖分离（2026-11-15 实测确立）**：**环境与暗部必须冷，光与受光面才暖**。
  实测三张达标参考图的整体冷暖（R−B，负=冷）分别为 **−47.0 / −0.8 / −28.8**；
  而"整体暖"的产出是 **+31 ~ +54**，且**暗部同样是暖的**（+5.6 ~ +18.7）——
  没有冷暖分离，暖光就退化成一片暖褐，画面只会闷。
  ❌ **不要写「暖色主导」**——它要求整张图暖，是"闷"的直接原因。
  ✅ 正确写法：**冷调环境**（青灰 / 蓝灰 / 藏青 / 靛紫的墙、货架、地面、阴影）
  **＋ 暖色光**（暖赭石 / 古金的受光面、轮廓光、皮肤）
  —— 这正是新海诚级光的结构，也是三张达标图的共同结构
- **光分两层，不要混写**：
  - **叙事光**（光源写实）：画面内的光源必须真实存在且画内可见（窗、路灯、屏幕、吊灯）——**不允许无来源的造型光**
  - **渲染光比**（方向/明暗/色温/氛围）：**由风格锚继承**，不由提示词另写。锚里是什么光，镜头里就是什么光
- **可测量的审美下限**（2026-11-15 立）：参考图与成片的平均饱和度 **≥ 0.28**；
  低于此即为「淡而无光」，判废重做。低于 0.10 基本等于白纸（v1 实测的角色设定表是 0.05–0.17）
- **锚的制品必须是「美图」**：角色锚 = **带光的美图版定妆照**（同脸 + 侧逆光 + 暖调 + 浅景深 + 真实环境），
  不是"全身正面 + 纯背景"的设定表。设定表按行业惯例就是不美的功能性文档；
  按 imagecraft A1，**锚定平庸等于锁死平庸**
- 构图：主角占画面 1/3–2/3，避免居中站桩

## 声音

- 音色：以提示词描述词锁定，每条镜头逐条人工比对
- 环境音层至少两层（近景 + 远景）
- 音乐克制：情绪推进时才进入
