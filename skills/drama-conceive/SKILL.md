# drama-conceive — 创意构思

**本阶段唯一产出**：`workspaces/<work-id>/creative/brief.md`。

这个阶段不涉及分镜、提示词、成本、轮询、验收——那些是后续阶段的事，本技能里一个字都不提。用户在这个阶段要的是**有人陪他把故事想明白**，不是一份流程说明。

---

## 0. 开工前

```bash
# 还没有作品工作区时先建一个（work-id 用 <slug>-<yyyyMMdd>）
python tools/drama/drama.py init <work-id> --title "暂定名"

# 项目级创作宪法（作品内有 constitution.md 时以作品级为准）
python tools/drama/drama.py constitution

# 创意简报的模板骨架
python tools/drama/drama.py template brief
```

**标题在讨论中才定下来是常态**，定了之后改：

```bash
python tools/drama/drama.py work set-title "<最终标题>"
```

---

## 1. 开场：先问对第一个问题

不要一上来抛一串问题。先用一句话复述用户已经说过的，指出缺口，然后**只问一个**最能分叉整个作品的问题，并给 2–3 个具体选项。

| 用户的状态 | 第一个问题 |
|---|---|
| 已经讲了一个故事 | 不问"想做什么"，直接追问内核（见 §2） |
| 完全空白 | 先问**视觉形式**：真人写实 / 动画 / 定格 / 3D CG。这一项决定后面整条生成路线能不能走通 |
| 只有一个题材词 | 先问**体量与观看场景**：手机竖屏短剧 / 横屏微电影 / 品牌短片 / 节日贺岁 |

给选项，不给开放式提问：「你想要什么感觉？」会让用户也累；「更接近 A 还是 B？」才是能回答的问题。

---

## 2. 追问内核：五个洞

对已经有雏形的想法，逐个挖。**问一个，等一个回答**，不要一口气列五个。

1. **主角现在最想要什么？** —— 要具体的东西，不是状态（"想要回邮件"可以，"想要被理解"不行）
2. **什么挡着他？** —— 人 / 制度 / 身体 / 时间 / 自己的习惯
3. **拿不到会失去什么？** —— 代价。答不出代价，冲突就没有重量
4. **冲突在哪个具体场景爆发？** —— 地点 + 时间 + 在场的人。**这是分水岭**：答不出场景 = 内核还没成型
5. **结尾观众应该看到什么改变？** —— 哪怕只变了一点

---

## 3. 收敛循环：三轮法

### 第 1 轮 —— 给三个方向，不是三个措辞

三个方向必须来自**不同的冲突引擎**（例如：一个靠外部阻力、一个靠内部缺陷、一个靠时间压力）。每个方向只给四行：

- 一句话内核
- 主角此刻的处境
- 一个画面（钩子）
- 观众为什么会看到最后

不要给三个只差措辞的东西。用户挑不出差异，说明这不是三个方向。

### 第 2 轮 —— 在选定方向上做变体

**只改一个变量**（换冲突引擎 / 换情绪落点 / 换视觉形式），给出 2 个变体。改两个以上就分不清用户到底喜欢什么。

### 第 3 轮 —— 写成 brief.md，逐项确认

不要一次性贴出整份 brief 等一句"行不行"。按顺序确认，一次一块：

内核 → 主角三件套 → 冲突场景 → 视觉钩子 → 风格与禁区

用户改主意是**常态，不是失败**。改了只重写受影响的字段，别为了保持一致性劝用户留在原方案上。

---

## 4. "敲定"的判据

进入 outline 之前，五条必须全过：

1. **一句话内核能对陌生人讲清楚**，且不是"讲述某人的某段经历"这种空转。
2. **主角三件套齐全**：具体欲望 + 具体阻力 + 具体代价。
3. **冲突有场景**：能用「地点 + 时间 + 在场的人」一句话说出来。
4. **有视觉钩子**：一个观众会记住的画面或声音。
5. **能写出主角的第一句台词** —— 写不出来，说明人物还没立住。

任何一条不满足，就回上一轮，**不要进入 outline**。

---

## 5. 反平庸三问

写完 brief 自查：

- **去掉主角名字**，这句话还成立吗？（"一个普通人决定改变人生" → 太泛，必须具体化）
- **内核动词**是"失去 / 成长 / 救赎 / 和解"吗？是的话必须落到具体事件，否则换掉。
- **主角的行为可演吗？** 是动词（"等待""拆信""签字""把伞递过去"）还是抽象状态（"内心挣扎""犹豫不决"）？抽象状态拍不出来。

---

## 6. 落盘与交接

模板骨架：`python tools/drama/drama.py template brief`

写进 `workspaces/<work-id>/creative/brief.md`，然后登记并推进：

```bash
python tools/drama/drama.py asset add creative/brief.md --type doc --notes "创意简报"
python tools/drama/drama.py advance --stage outline --note "创意已敲定"
```

`advance` 会校验 `creative/brief.md` 是否存在——没写就推进不了，这是刻意的。

---

## 7. 边界

- **不写**分镜、镜头编号、H3 提示词、参数、成本——那是后续阶段。
- **不**产出三个方案让用户"挑个更清晰的"就宣布完成；必须收敛到**一份**。
- **一次只问一个关键问题**，等回答再往下。
- **不替用户做审美决定**：给选项，不给"你觉得呢"。
- brief 里"待确认"一栏保持诚实——没敲定的点写上去，别糊过去。
