## 0. 实验设计

**基准**：`BASE` = 用户原图当风格锚 + 影视CG机制型词表 + 16:9 中近景 + 2 条排除。
**变量组**：A 锚质量 / B 词表簇 / C 排除项数量 / D 题材。
**样本**：14 张，2K，编辑通道（1 参考图），成本约 ¥2.5。

---

## 1. 案例 A：锚的质量是天花板（4 张对照）

同一段提示词（竹林女剑客，中近景），只换风格锚：

| 编号 | 锚 | 输出特征 |
|---|---|---|
| P1 | 用户原图（最佳样本） | **最高档**：体积光成束、竹林纵深分明、面部有颧骨与下颌结构、织物质感厚重 |
| P2 | 我上一轮生成的 CG 男图 | **次高档**：暖轮廓光、前景竹竿斜插出纵深、脸略柔但有结构 |
| P3 | 手游立绘女图 | **掉档**：光比平、背景层次薄、脸幼态化、衣料像绒布 |
| P4 | 我上一轮的"好图"（桃林 v2） | **掉档**：脸明显娃娃化、光平、纱裙像针织 |

**结论**：
1. 锚的质量直接决定输出档位（差一档就是差一档）。
2. **锚会连带继承骨相与光比**——P4 的锚本身脸就柔，输出就柔。
3. **自产锚会降级传递**：我的 v2 单看是"好图"，但当锚用时输出掉档。
4. 题材与锚同族（雪松林仙侠 → 竹林剑客）时，输出自动更稳。

## 2. 案例 B：词表分簇（4 张对照）

同一锚、同一主体（桃林少女），只改词表：

| 编号 | 词表 | 输出特征 |
|---|---|---|
| BASE | 影视CG机制型 | 好：冷暖对比、发丝轮廓光、真实焦外、背景层次 |
| P5 | 中性客观描述 | **最差**：平光、无纵深、无体积光、构图平庸、脸僵 —— **陷阱档** |
| P6 | 摄影器材名词（ARRI/50mm/胶片颗粒） | 偏"影楼写真"，面部光平、暗部层次弱 |
| P7 | 二次元标签（国漫/仙侠/立绘/仙女/俏皮） | **掉进手游立绘簇**：大眼小鼻、超高饱和、大飘带、梦幻 bokeh |

**结论**：**词表是比锚更强的杠杆**。最稳是机制型（镜头几何+光位+材质+调色）；器材名词会偏写真；标签词直接拽进插画簇；**中性客观描述是最危险的写法**。

## 3. 案例 C：排除项数量（3 张对照）

同一 prompt，0 条 / 2 条 / 7 条排除：三者差异大到超过题材差异。
**7 条否定那版出现了明显的幼态化（大眼、圆脸、婴儿肥）与柔焦** —— 印证「否定项会反向激活被否概念」。
但受采样方差影响，**"几条最优"这条结论证据不足**，只保留方向性结论：**排除项 ≤2 条，其余改正向替代**。

## 4. 案例 D：题材与语汇距离（5 张对照）

| 编号 | 题材 | 表现 |
|---|---|---|
| P10 | 雪松林月夜 · 男剑客 | **最高档**，甚至强于原参考图：体积光、冷调、雾中纵深、袍子厚重 |
| P11 | 竹林晨雾 · 少女 | 中上，但脸偏幼、织物质感软 |
| P12 | 古代宫殿回廊 · 少女 | 光影漂亮（窗格投影/逆光），脸偏柔、构图裁切略乱 |
| P14 | 当代城市雨夜 · 都市女性 | **高**：冷蓝+暖橙霓虹、湿地面反光、雨丝、人脸成熟冷峻 |
| P13 | 面部特写 1:1 | 五官细节达标，但整体仍偏"角色立绘"——**1:1 特写自带立绘先验** |

**结论**：**题材本身不决定质量**（现代城市雨夜 ≠ 仙侠，但质量同样高）。决定质量的是
① 锚的语汇距离 ② 是否给了可执行的影调机制 ③ 景别与构图先验。

## 5. 由此升级的规则

| 规则 | 来源 |
|---|---|
| A1 锚决定天花板（含骨相与光比继承） | 案例 A |
| A2 锚沿链降级，禁止自产锚当风格锚 | 案例 A + 探索期失败图 |
| A3 词表分簇，中性客观描述是陷阱 | 案例 B |
| A4 脸占比 <1/6 必然脸废，1:4 是甜点 | 探索期全身立绘 vs 中近景 |
| A5 否定项反向激活，排除项 ≤2 条 | 案例 C + drama 配方实测（not a villain） |
| A6 单次采样方差大，n≥2 + 读数比对（`image_qc.py`） | 案例 C |
| A7 纵深靠三层遮挡，不靠堆料 | 案例 D（竹林/雪松/柱列） |
| A8 大尺寸多脸拼图会被输入审核拒并卡死会话 | 2026-11-15 三次会话事故（见 `探针方法论.md` §3.0） |
