# 影调与光

> 画面「有质感 / 没质感」的开关。这里给可直接复制的语汇。

---

## 1. 质感 = 几何 + 光位 + 材质 + 调色

模型不认「电影级」「高级感」这类形容词，它只解析可执行的机制描述。四件套缺一，质感就塌：

```
① 镜头几何   焦段感 / 景别 / 机位高度 / 景深 / 前景遮挡物
② 光位与光比 主光方向与性质 / 明暗对比 / 暗部是否压死 / 补光 / 轮廓光 / 体积光
③ 材质       织物的厚薄与织纹 / 皮肤微纹理 / 金属反射 / 纱的透光
④ 调色       主调 / 饱和度 / 冷暖关系 / 明度分区
```

---

## 2. 镜头段模板

```
35mm 电影镜头，中近景（腰部以上），人物居中，机位与眼齐平，
浅景深，背景〔场景元素〕虚化成柔和色块，前景一枝〔某物〕虚化入画
```

变体：
- 特写：`85mm 电影镜头，胸部以上特写，头部约占画面一半，极浅景深`
- 广角带环境：`24mm 电影镜头，略仰机位，人物占据画面下半，前景柱列形成纵深引导线`
- 稳定器跟拍感：`镜头高度与肩齐，背景有轻微运动模糊拖影`

**前景遮挡物是性价比最高的一句**——一句 `前景一枝桃花虚化入画` 直接给出纵深与镜头感，成本为零。

## 3. 光线段模板

### 影视级默认（最稳）

```
低调侧逆光为主光，从人物左后上方斜射，轮廓光勾勒发丝与衣缘；
暗部保留细节不压死，柔和面光补亮面部；暖光与冷雾形成冷暖对比
```

### 室内窗光

```
黄昏暖阳穿过〔雕花窗棂〕投下窗格光影，低调侧逆光勾出发丝与衣缘，
暗部保留细节，室内冷调阴影与窗外暖光形成冷暖对比
```

### 夜景霓虹

```
雨夜低调侧逆光，霓虹反射光作为柔和补光勾出面部与肩线轮廓，
暗部保留细节不压死，冷蓝与暖橙形成冷暖对比
```

### 雾林体积光

```
体积光从林间斜射成束穿过雾气，冷雾弥漫，暗部保留细节
```

### 关键光位词

| 词 | 效果 |
|---|---|
| 低调侧逆光 | 默认首选，立体感与轮廓兼具 |
| 顶光 | 眼窝阴影，不建议当主光 |
| 底光/鬼光 | 恐怖化，除非刻意 |
| 柔和平光 | 保险但平，容易掉档 |
| 环形光 | 无方向，脸会平 |
| 侧窗光 | 立体、有影 |

## 4. 色彩段模板

```
低饱和电影调色，〔主色〕与〔对比色〕并置，不要通体高饱和〔某色〕
```

变体：
- 冷蓝调：`低饱和青蓝调色，暗部压向蓝灰，高光保留微暖`
- 暖调：`低饱和暖褐调色，暗部保留橙棕倾向`
- 粉桃：`低饱和电影调色，樱粉与青灰冷雾并置，不要通体高饱和粉`

**「不要通体高饱和X」是必写项**：高饱和+无暗部 = 插画感。

---

## 5. 纵深三层（实锤规则 A7）

```
前景：〔一枝桃花／一道纱帘／一根竹竿／一截湿栏杆〕虚化入画
中景：主体清晰，占画面 1/3–1/2
背景：〔竹林／柱列／雪松林〕层层虚化，元素重复形成韵律
```

**不要靠堆花瓣 / 堆雪片造氛围**——散落元素只增加噪点，不增加纵深。纵深靠"前后遮挡关系"。

---

## 6. 材质控制词

| 对象 | 词 |
|---|---|
| 厚重织物 | `织物厚重，有自然褶皱与重量感，织纹清晰` |
| 薄纱 | `纱质层叠，边缘透光，随动作飘起` |
| 皮肤 | `保留真实皮肤微纹理与面部绒毛，颊侧有柔和腮红` |
| 金属 | `银色雕花护腕，金属有磨损的柔和高光` |
| 湿面 | `雨后湿润反光` |
| 发丝 | `发丝分股清晰，逆光下发梢透光` |

---

## 7. 一致性检查（多镜头时）

同一场景/同一角色连续出图时，这三项必须逐字复用，否则一定漂：

1. **光位句**（主光方向 + 暗部处理）
2. **色彩句**（主调 + 对比色 + 饱和度）
3. **镜头句**（焦段 + 景别 + 占幅）

其余（人物细节、场景细节）可微调。复用方式：把上一次的成品设为**风格锚**，并把三句照抄。
