# drama-script — 分场剧本与台词

**本阶段产出**：`workspaces/<work-id>/scenes.json` 的 `beats`（每场：动作 + 台词）。

---

## 0. 开工前

```bash
python tools/drama/drama.py next --work <work-id>
python tools/drama/drama.py constitution
python tools/drama/drama.py scenes read --work <work-id>
python tools/drama/drama.py characters read --work <work-id>
```

角色的说话方式在角色卡的 `voice` 字段里；不要另起一套。

## 1. 一场戏怎么排

一场 = 一串 **beats**。一个 beat 是一个动作单元，可能带台词：

```json
"beats": [
  {"action": "掌柜把笔搁上笔架，抬眼看她——第一声喊得很轻，像在点一个号",
   "speaker": "shopkeeper", "text": "十九。", "mode": "dialogue",
   "delivery": "第一声，轻，像点号，尾音不扬，落下即止"},
  {"action": "她没应；左手小指压住纸角，笔尖悬在纸面上方",
   "speaker": null, "text": null, "mode": null},
  {"action": "他叫第二声，手指在笔架上按了一下——这一声比刚才重",
   "speaker": "shopkeeper", "text": "十九。", "mode": "dialogue",
   "delivery": "第二声，重，压着火气，字尾压下去"},
  {"action": "还是没应；他的目光在她低着的头顶停了一下，又落回账本",
   "speaker": null, "text": null, "mode": null},
  {"action": "她继续写，笔压得比刚才重",
   "speaker": null, "text": null, "mode": null}
]
```

**动作行先写，台词后配。** 反过来容易写成"边说边走"的动作清单——那是分镜，不是剧本。

节奏：一个 beat 一拍。一场戏 6–12 个 beat。**对话密集的场次可以更多**——
两个挨着的人交谈，如果一方喊完另一方毫无反应，那就是有声书，不是戏。

## 1.5 表演层：这一层决定成片是不是「烂片」

> R18。2026-11-12 用户判定：SC02「连喊三声十九 + 一声在」画面与声音「完全在两个宇宙」，
> 两人毫无情绪、毫无波澜、毫无动作，「只够坐在有声书的那一桌」。
> 体检后定位到**主因在剧本层**——提示词和分镜是放大器，不是源头。

### 三条硬规矩

**① 否定式表演词禁止进动作行**

`始终没抬眼` / `笔没停，头不抬` / `一动不动` / `没有反应` —— 这些在生成端等于木头人。
**「没有动作」不是克制，是禁止表演。**

克制要写成**被压住的动作**：

| ✗ 否定式 | ✓ 压住的动作 |
|---|---|
| 始终没抬眼 | 目光在她低着的头顶停了一下，又落回账本 |
| 笔没停，头不抬 | 笔尖在纸上顿住半拍才落下 |
| 一动不动 | 手指在笔架上按了一下 |
| 没有反应 | 她的呼吸停了一拍，笔尖偏出墨线半分 |

### ② 台词拍之后必须有反应拍

每个关键台词拍后面要有一个**承接对方台词的无台词动作拍**。
一方喊完，另一方没有动作——观众看到的就是两个人各说各的。

### ③ 重复台词必须三拍递进，拍与拍之间要有「没应」

同一句重复三次而语气完全相同 = 机器复读。
要拆成阶梯：**第一声轻（像点号）→ 第二声重（带动作）→ 第三声慢而沉（带重量）**，
中间夹「没应」的无台词拍。**沉默本身要有内容**（屏息、迟疑、笔尖悬停、屏住的手）。

### ④ 一镜装不下就加长场次，不要塞

实测 6.58 秒的镜头里念白只占 1.8 秒，**其余 4.8 秒是零内容沉默**。
一场戏的 `duration` 装不下「三声 + 一声 + 反应 + 停顿」→ **加时长**，别把停顿挤掉。
停顿是戏，挤掉了就只剩台词。

### ⑤ 语气逐句另写（R9）

每句台词带 `delivery`：情绪 + 语速 + 气口。
同一角色不同台词的 `delivery` 必须不同——全片同一口气听起来就是有声书。

> ⚠️ **别把语气写进 `voice_desc`**。`voice_desc` 只放**音色**（声线质感、性别、音域），
> 逐字复用；语气属于 `delivery` / `delivery_default`，逐句变。
> 详见 `docs/数据契约.md` §7。

## 2. 台词怎么写

### 硬约束

- 单句不超过 25 字；口语短句
- **不解释设定**——不说"因为我从小……所以……"
- 情绪靠**动作和停顿**承载，不靠形容词堆叠
- 不用书面语长句

### 角色要能听出来

用角色卡里的 `voice`：句长、用词、是否用敬语，三者差一两条就够。

最有效的做法是**长度和完整度**——让阿铃只说一个字、让掌柜说完整句子。不要靠口头禅（"这个小妖精"）来区分，那是廉价的。

### 台词时长换算

```
台词总字数 ÷ 4.5 ≈ 需要的秒数      # 中文约 4.5 字/秒，留气口
```

一场的 `duration` 装不下台词 → 两条路：**删台词**或**加时长**。别塞。塞进去的念出来是赶的，而且会挤掉动作。

### mode 只有两种

| mode | 含义 | 口型 |
|---|---|---|
| `dialogue` | 画内音，角色在画面里说话 | **有** |
| `voiceover` | 画外音，不在画面里说话 | **无** |

要口型就用 `dialogue`。写成 `voiceover` 又指望人物张嘴，模型会让嘴保持紧闭——官方 voiceover 模板里那句 "his lips remain completely closed" 是**明确指令**，实测 T2/T3 完全无口型。

`voiceover` 的正当用途：真正的旁白、内心独白、看不见的画外人物。旁白还要额外说明"画面里的角色嘴唇完全不动"。

## 3. 把 brief 的视觉钩子落到某一场

brief 里的「视觉钩子」不能只停在设定里，它必须在**某一场被看见或被听见**。

指定它落在哪一场——通常是最开场或最收尾。写完检查：那一场的 `beats` 里真的有它吗？

## 4. 检查

### 4.1 念白检查

- 把这场戏**念出来**给用户听——听得懂吗？
- 每个角色开口，**能认出是谁**吗？
- 有没有台词在解释设定？删掉，让动作去说。
- 台词总字数 ÷ 4.5 ≤ 场次 `duration` 吗？
- brief 的「待确认」里标 `script 前定` 的条目解决了吗？
- 道具在这场戏里**有戏份吗**？（关键道具的戏份往往在 beats 里被漏掉）

### 4.2 表演层检查（必跑体检）

```bash
python tools/drama/beat_qc.py --work <work-id>
python tools/drama/beat_qc.py --work <work-id> --scene SC02 --json
```

四项指标：

| 指标 | 判定线 | 含义 |
|---|---|---|
| 反应拍覆盖率 | **≥50%** | 每个台词拍后面有没有承接的无台词动作拍 |
| 否定式表演词 | **0** | 动作行里有没有「没抬眼 / 一动不动」这类禁止表演的写法 |
| 可拍位移动词 | 提示 | 动作行是不是只有心理/状态描述，没有能上镜的动作 |
| 沉默占比 | 参考 | 台词拍里的静默是不是零内容 |

**覆盖率 <50% 的场次不许进分镜。**

体检只报问题，不改写。**改写要人来做**——它只告诉你「这里没戏」，
「怎么改成有戏」是编剧的活。

### 4.3 人工过一遍（机器查不出来的）

- 沉默的那几秒，观众在**看什么**？有东西可看吗？
- 两个人挨着说话，一个人的台词另一个人的**身体有反应吗**？
- 同一句重复出现，情绪**递进了吗**？还是复读？
- 克制的地方，观众能感到**压住的力度**吗？还是只感到「没反应」？

## 6. 边界

- **不写**景别、机位、时长参数——那是 storyboard。
- **不写**提示词——那是 generate。
- 不改角色设定（characters 阶段的事）；发现角色卡与台词矛盾，退回 characters。
- 不在这里碰成本。
