# 验收清单

> 对应数据契约第 7 节的 `verify/<shot-id>.report.json` 格式。
> 阶段 Skill 的验收逻辑以此为准。

## A. 技术参数（ffprobe 自动判定，**可判废**）

| 检查项 | 通过标准 | 自动化 |
|---|---|---|
| 实际时长 | 与计划时长偏差 ≤ 0.5s | ✅ ffprobe |
| 分辨率 | 等于计划的 768P（1344×768） | ✅ ffprobe |
| 宽高比 | 等于 16:9（偏差 ≤ 0.02） | ✅ ffprobe |
| 视频编码 | H.264/HEVC，无异常帧 | ✅ ffprobe |
| 音频流存在 | 必须有 audio 流 | ✅ ffprobe |
| 非静音 | mean_volume > -45dB | ✅ volumedetect |

**A 组任一不通过 → 直接判废，不做人工评审。**

## B. 音画同步（视频理解语义判定，**仅作参考**）

| 检查项 | 参考标准 |
|---|---|
| 对白逐字一致 | 说出的话与剧本台词完全一致 |
| 发声者正确 | 声音归属于画面中的正确角色 |
| 环境音匹配 | 画面是雨夜就应有雨声 |
| 无多余旁白 | 未要求时不应出现额外人声 |
| 口型符合预期 | **画内音应有口型，画外音应无口型** |

## C. 角色一致性（跨镜头对比，需人判）

| 检查项 | 通过标准 |
|---|---|
| 身份特征保持 | 发型/脸型/服装/体型与参考图一致 |
| 服装状态正确 | 湿身镜头衣服必须湿、头发必须贴额头 |
| 道具正确 | 琴的深红棕色木色、贴纸位置与形态 |
| 跨镜头同一人 | 相邻镜头中人物为同一人 |

## D. 叙事完整性（需人判）

| 检查项 | 通过标准 |
|---|---|
| 镜头意图达成 | 拉琴镜头能看出"一个人在雨中拉琴" |
| 情绪传达 | 孤独、沉静的情绪可被感知 |
| 可用性 | 达到"生产可用级别"——可直接进粗剪，不需重生成 |

## E. 成本核对

| 检查项 | 通过标准 |
|---|---|
| 实际计费 | 与预估一致（H3 768P 5s ≈ $0.40/条） |
| 废片率 | 验证阶段不计，量产阶段统计 |

---

## 判定规则

- **A 组不通过** → 直接废弃重生成，不做人工评审（省时间）
- **B 组不通过** → 判为废片或进入二次调参（调**提示词**，不是调参数）
- **C/D 组不通过** → 判定参考图策略失败 → 改用首帧模式（I2VA）或增加参考图数量
- **全部通过** → 进入下一阶段，成片归档

---

## 强制要求

**机器判定与人工判定冲突时，以人工为准。**

实测证据：`videos_understand` 对同一段视频的相机运动判定不自洽
（T1 判 "Static"，T2/T3 判 "slow push-in"；逐帧对比证明是缓慢推近）。

因此：
- `tech` 段由 `drama verify` 自动生成
- `semantic` 段由视频理解生成，**仅作参考**
- `human` 段**必须人工填写**才能把 `verdict` 定为 `pass`

## 人工复核方法

```bash
# 抽取首/中/尾三帧
ffmpeg -y -i <video> -vf "select='eq(n\,0)+eq(n\,60)+eq(n\,120)',scale=768:-1" -vsync 0 frames/k%02d.jpg
```

看三帧确认：角色身份、**服装状态**、道具、口型、跨镜头一致性、情绪。

## 参考值

| 指标 | 观察值 | 判定阈值 |
|---|---|---|
| mean_volume（有对白） | -14 ~ -19 dB | — |
| mean_volume（纯环境音） | 约 -29 dB | — |
| mean_volume（无声废片） | < -45 dB | 判废 |
| 实际生成耗时 | 约 2 分钟/条 | — |
| 单条成本（768P 5s） | $0.40 | — |
