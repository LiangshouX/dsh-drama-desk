# 全流程制作的迭代路线

产品目标：在导演工作台内流畅完成 AI 短剧与微电影的创意、写作、视觉准备、镜头生产、审片返工、装配与交付。舒适的标准是：随时看得懂当前作品、知道下一步、能就地决定和修改，离开再回来能接着做。

## v0.2：基础制作闭环

本轮已实现：

- 空作品可新增场次、角色、道具与镜头；字段继续用统一的原地编辑器。镜号由 Host 分配，角色 ID 保持稳定。
- 文件放入作品后，可登记到资产索引，实际计算哈希、测量视频音频。镜头详情可选择当前视频版本、覆盖的拍号和参考资产。
- 制作助手覆盖九阶段；阶段切换更新会话的查看上下文，提供本阶段任务、出口与前置缺口。复制任务后由导演在宿主原生对话里发起，切页不自动发消息。
- 缺机器报告时也能记录人工意见，未知的机器结果保持未知。明确确认本镜验收通过才设置 verified；人工复核绑定视频资产与版本。
- 本地 FFmpeg 粗剪，横屏、竖屏、方形三种输出。按当前分镜顺序保留整个片段与原声，无声补静音、画幅不符留黑边，统一 24fps。
- 导出任务有磁盘进度、错误与重启中断提示。完成即登记新成片和来源清单，不覆盖历史版本。交付页支持回看、下载、确认交付与来源变更检测。
- agent 工具与界面走同一 Host service。插件本身不发起付费生成。

验收：构建、客户端冒烟与既有等价性回归；新增自动化覆盖空作品创建、当前版本选择、人工复核、真实 FFmpeg 音视频装配、重复提交、并发资产登记、交付、来源过期和 HTTP Range。

## 后续重点

1. **创作工作流**：场次与镜头的受控删除、重排、复制；引用与资产迁移预览；多集结构。不能通过静默改号破坏已生成的历史资产。
2. **生产调度**：将导演批注、待生成清单与预算交给 agent 的可审阅任务；失败与中断恢复、逐镜重试；接入真实第二个生成模型后再抽供应商适配。
3. **剪辑与声音**：入出点、片段排序方案、字幕、配音、音乐与混音；粗剪之外的精剪版本。新增变换继续走随包工具，不在 UI 复制编译逻辑。
4. **资产体验**：从系统文件选择器复制导入、引用和角色绑定、作废归档、版本并排比较；始终保留来源和旧资产。
5. **交付质量**：规格配置、人工审片清单、字幕与封面等交付包、多端尺寸预览。

每轮用一个独立的小作品走通，再用大作品检查性能与窄面板。付费生成只在导演明确授权且预算可见时由 agent 执行。
